政策与背景：火电为什么"红利化"

整个策略的宏观前提：政策把火电从"周期股"改造成"红利/公用事业股"。这决定了后面归因怎么判 A/B。

核心判断：火电红利化（三重挤压）

成本被框稳：长协煤价 570–770 绿色区间（303号文）→ 煤价冲击变少
电价被框住：市场化改革 ±20% 浮动（1439号文）→ 电价能涨能跌，弹性受限
份额被挤占：风光优先上网、装机大超预期 → 火电发电空间被永久挤
→ 结论：火电从"赚煤电价差的周期股"变成"吃稳定现金流+分红的红利股"

政策断点时间轴（因子校验基准）

三个五年规划：前两轮均超额达成 （点卡片看目标 vs 实现）

前两轮（十三五/十四五）规划目标均超额达成 → 十五五"煤电转支撑调节性电源"的可信度高，可当基准假设。

政策外推 → 火电因子取舍（方向假设）

这是从政策外推的方向假设：煤价类因子降权（被框稳）、电价/风光挤占改做"A-永久判定器"、红利/现金流类因子优先。

火电漏斗：跌得多 ≠ 跌错了

用真实事件一步步推导：同样是超跌，怎么区分"错杀（该反弹）"和"价值陷阱（活该跌）"。

先看两个真实事件的对比（漏斗的起点）

例1：2022-10 华能超跌 −16.4%

表面：政策环境看着不好，股价大跌，像是"该跌"。

但查真实数据：电价 +18%（缺电涨价）、煤价平、水电偏枯少挤占 → 基本面根本没坏！

判定：B类·错杀 → 跌错了，该反弹 → 事后 t+60 +7.3% ✅ 修复了

例2：2024-07 华能超跌 −17.8%

表面：股价便宜了，看着像抄底机会。

但查真实数据：电价 −2.85%（下行）+ 风光挤占重 + 水电丰水 +10.5% 再抢 → 基本面真的变差了！

判定：A类·永久 → 价值真下移，别碰 → 事后 t+60 −10.7% ❌ 继续跌（陷阱）

这两个例子推出漏斗的核心：光看"跌了多少"没用，必须查基本面（煤价/电价/风光/水电）判断"跌得该不该"，这就是 A/B 归因。

由例子归纳出的 4 层漏斗 （点击展开细节）

怎么筛：火电指数相对沪深300的 60 日超额收益 ≤ 历史 5% 分位（阈值 −16%）→ 触发。
为什么：用"相对沪深300超额"排除大盘普跌；用"历史分位"自适应，不主观拍阈值。只用价格、不掺因子 → 防循环论证。
结果：10年筛出 7 次。
用什么：高股息率、高FCF收益率、低PB，都是"跌得有价值"的标。
频率处理：财务值（年频）÷ 股价（日频）→ 比值是日频信号。
防未来函数：财报用公告日滞后（当年年报次年4月才披露）。
用上面两个例子的 A/B 归因：
· A类永久 电价下行/风光挤占（如2024）→ 价值真下移 → 剔除（陷阱）
· A类周期 煤价冲击（如2020）→ 会回摆 → 看周期位置
· B类错杀 基本面没坏（如2022电价+18%）→ 保留（真机会）
价值：第2层"便宜就买"会踩陷阱，永久变差的股越跌越"便宜"，这一层专门排雷。
打分：综合分 = zscore(FCF收益率) + zscore(前期抗跌)，选前5等权持有60天。
为什么这2个：回测排榜里最 work（高FCF均值 +6.2%、前期抗跌 RankIC 最高）。
⚠ 但中位数一看就弱（见下面"均值 vs 中位数"）。

  1. 纯火电超跌不修复（+0.14%），单纯抄底火电难赚

  4. 诚实边界：样本7次，方向性结论，非统计铁证

水电漏斗：把"煤价"换成"来水"

水电没有燃料成本，"燃料"就是来水。同样的 A/B 框架：丰水年跌=错杀，枯水年跌=真跌。

先看两个真实事件的对比

例1：2024-10 水电超跌

查来水：2024来水丰（全国水电发电 +10.5%）→ 基本面好却跌 = 错杀

判定：B类·错杀 → t+60 +5.0% ✅ 修复

例2：2025-07 水电超跌

查来水：2025 Q3来水偏枯 −8%、单季发电降10–17% → 基本面真差 = 真跌

判定：A类·周期 → t+60 −13.8% ❌ 修复失败（枯水年抄底=踩坑）

推出水电的核心规律：水电超跌能不能抄，取决于跌的时候是丰水还是枯水。丰水年跌=错杀（抄），枯水年跌=真跌（别碰）。这就是火电 A/B 框架的迁移，"煤价"换成"来水"。

水电漏斗 （点击展开细节）

11只纯水电等权合成指数，相对沪深300的60日超额 ≤ 历史5%分位（阈值 −14.4%）→ 触发。2018至今筛出6次。
水电没有煤价，"燃料"就是来水。查当年来水/水电发电量同比：来水多=发电多=利好；枯水=利空。
· B类错杀 丰水年却跌（如2024丰水 +10.5%）→ 基本面好却跌 → 会修复（抄）
· A类周期 枯水年跌（如2025 Q3枯水 −8%）→ 基本面真差 → 不修复（别碰）
2025那次亏 −13.8% 就是踩了"枯水年抄底"的坑。
水电同质化（都是稳定现金流+高分红）→ 选股（挑哪只）无效。应做择时、且挑龙头：实测6只水电只有长江电力的超跌信号真正显著（+5.3%，p=0.03）。

水电结论

  1. 水电超跌看来水：丰水年跌=错杀（抄），枯水年跌=真跌（别碰）

  4. A/B 框架跨板块通用：火电的"煤价" = 水电的"来水"
